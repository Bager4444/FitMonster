# ⚡ Быстрый старт - AI Ассистент

## 🚀 За 5 минут

### 1. Запустите приложение
```bash
flutter run
```

### 2. Откройте AI ассистента
- Найдите иконку чата 💬 на главной странице
- Или перейдите через меню

### 3. Задайте вопрос
Попробуйте один из примеров:
- "Как накачать бицепс?"
- "Что есть после тренировки?"
- "Мотивируй меня!"

### 4. Получите персонализированный ответ
AI учтет ваш профиль и даст конкретные рекомендации.

## 📖 Основные возможности

### Тренировки 💪
```
Вопрос: "Могу сделать 15 подтягиваний"
Ответ: Персональная программа на основе вашего уровня
```

### Питание 🍎
```
Вопрос: "Что есть после тренировки?"
Ответ: Конкретные блюда и граммовки
```

### Мотивация 🔥
```
Вопрос: "Нет сил тренироваться"
Ответ: Поддержка и вдохновение
```

### Контекст 🧠
```
Вопрос 1: "Как накачать бицепс?"
Вопрос 2: "10" (количество подтягиваний)
Ответ: AI понимает контекст и дает программу для 10 подтягиваний
```

## 🛠️ Устранение проблем

### AI не отвечает
1. Проверьте интернет-соединение
2. Подождите 30 секунд (timeout)
3. При ошибке сработает fallback с базовыми ответами

### Ответы не персонализированы
1. Заполните профиль (имя, противопоказания, аллергии)
2. Тренируйтесь для повышения уровня
3. Задавайте более конкретные вопросы

### История не сохраняется
1. Проверьте разрешения приложения
2. Очистите кэш и перезапустите
3. Переустановите приложение

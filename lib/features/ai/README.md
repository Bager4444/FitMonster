# AI Ассистент - Персональный Фитнес Тренер

## Описание

AI Ассистент использует DeepSeek API для предоставления персонализированных рекомендаций по тренировкам, питанию и мотивации.

## Возможности

### 1. Персонализация
- Учитывает профиль пользователя (имя, уровень, противопоказания, аллергии)
- Адаптирует рекомендации под текущий уровень пользователя
- Помнит контекст предыдущих сообщений

### 2. Тренировки
- Программы для всех групп мышц (бицепс, трицепс, пресс, спина, грудь, ноги, плечи)
- Рекомендации с учетом опыта пользователя (новички, средний, продвинутый)
- Конкретные подходы и повторения
- Учет противопоказаний

### 3. Питание
- Рекомендации до/после тренировки
- Учет аллергий
- Конкретные примеры блюд и граммовки
- Советы по похудению и набору массы
- Информация о макронутриентах (белки, углеводы, жиры)

### 4. Мотивация
- Поддержка и вдохновение
- Персонализированные сообщения
- Отслеживание прогресса

### 5. Расширенная база знаний
- 15+ детальных программ тренировок
- Подробная информация о питании
- 5 вариантов мотивационных сообщений
- Советы по восстановлению
- См. [KNOWLEDGE_BASE.md](KNOWLEDGE_BASE.md)

## Технические детали

### Архитектура
```
lib/features/ai/
├── domain/
│   └── models/
│       └── ai_message.dart          # Модель сообщения
├── services/
│   ├── deepseek_ai_service.dart     # Реальный AI сервис (DeepSeek API)
│   └── ai_service.dart              # Старый сервис (fallback)
└── presentation/
    └── pages/
        └── ai_chat_page.dart        # UI чата
```

### DeepSeek API
- **Endpoint**: `https://api.deepseek.com/v1/chat/completions`
- **Model**: `deepseek-chat`
- **Temperature**: 0.7 (баланс между креативностью и точностью)
- **Max Tokens**: 1000 (достаточно для развернутых ответов)

### Системный промпт
Включает:
- Роль ассистента (персональный фитнес-тренер)
- Информацию о пользователе (имя, уровень, противопоказания, аллергии)
- Правила ответов (краткость, эмодзи, конкретика)
- Специализацию (тренировки, питание, мотивация)

### Fallback механизм
При ошибке API используется локальный fallback с базовыми ответами по ключевым словам.

### Примеры вопросов

**Тренировки:**
- "Как накачать бицепс?"
- "Программа тренировок для начинающих"
- "Могу сделать 15 подтягиваний, что дальше?"

- "Что есть после тренировки?"
- "Как похудеть?"
- "Рацион для набора массы"

**Мотивация:**
- "Нет сил тренироваться"
- "Мотивируй меня!"

## Безопасность

⚠️ **Важно**: API ключ в коде - это временное решение для разработки.

Для продакшена рекомендуется:
1. Хранить ключ в переменных окружения
2. Использовать backend proxy для API запросов
3. Ограничить rate limiting
4. Добавить мониторинг использования

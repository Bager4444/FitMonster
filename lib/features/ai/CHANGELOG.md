# Changelog - AI Ассистент

## [2.1.0] - 2026-02-25

### Добавлено
- 🧠 Расширенная база знаний для fallback ответов
- 💪 Детальные программы для всех групп мышц (бицепс, трицепс, пресс, спина, грудь, ноги, плечи)
- 🥗 Подробная информация о питании (до/после тренировки, похудение, набор массы, белок)
- 🔥 5 вариантов мотивационных сообщений
- 😌 Информация о восстановлении (сон, растяжка, массаж)
- 📚 Документ KNOWLEDGE_BASE.md с полной базой знаний

### Изменено
- 📝 Улучшен системный промпт с детальной базой знаний
- 🎯 Увеличен лимит слов в ответах (200 → 250)
- 🔄 Расширен fallback механизм с 3 до 15+ вариантов ответов
- 💡 Добавлены конкретные граммовки и подходы/повторения

### Улучшено
- ⚡ Более точные ответы благодаря расширенной базе
- 🎨 Лучшая структура ответов с эмодзи
- 📊 Программы для 3 уровней сложности (новички, средний, продвинутый)
- 🥩 Детальная информация о макронутриентах

## [2.0.0] - 2026-02-25

### Добавлено
- ✨ Интеграция с DeepSeek API для реальных AI ответов
- 🧠 Персонализация на основе профиля пользователя (уровень, противопоказания, аллергии)
- 💬 Контекстная память (последние 10 сообщений)
- 🎯 Автоматическое определение типа сообщения (тренировки, питание, мотивация)
- 🛡️ Fallback механизм при ошибках API

### Изменено
- 🔄 Переход с поиска по ключевым словам на реальный AI
- 📝 Улучшенный системный промпт с детальными инструкциями
- 🎨 Обновлен UI для работы с DeepSeekAiService
- 🐛 Исправлены deprecated методы (withOpacity → withValues)

### Технические детали
- **API**: DeepSeek Chat Completions
- **Model**: deepseek-chat
- **Temperature**: 0.7
- **Max Tokens**: 1000
- **Timeout**: 30 секунд

### Безопасность
- ⚠️ API ключ временно в коде (для разработки)

# Тестирование AI Ассистента

## Быстрый старт

### 1. Запуск приложения
```bash
flutter run
```

### 2. Навигация к AI ассистенту
1. Откройте приложение
2. Перейдите на главную страницу
3. Найдите кнопку "AI Ассистент" или иконку чата
4. Откройте чат

### 3. Тестовые сценарии

#### Сценарий 1: Тренировки
**Вопросы для тестирования:**
- "Как накачать бицепс?"
- "Могу сделать 15 подтягиваний"
- "Программа тренировок для начинающих"
- "Упражнения для пресса"

**Ожидаемый результат:**
- Персонализированные программы тренировок
- Конкретные подходы и повторения
- Учет уровня пользователя
- Иконка 💪 и тип "Тренировки"

#### Сценарий 2: Питание
**Вопросы для тестирования:**
- "Что есть после тренировки?"
- "Как похудеть?"
- "Рацион для набора массы"
- "Что есть перед тренировкой?"

**Ожидаемый результат:**
- Конкретные рекомендации по питанию
- Примеры блюд и граммовки
- Учет аллергий (если указаны в профиле)
- Иконка 🍎 и тип "Питание"

#### Сценарий 3: Мотивация
**Вопросы для тестирования:**
- "Нет сил тренироваться"
- "Мотивируй меня"
- "Устал"

**Ожидаемый результат:**
- Мотивирующие сообщения
- Персонализация с именем пользователя
- Упоминание текущего уровня
- Иконка 🏆 и тип "Мотивация"

#### Сценарий 4: Контекст
**Последовательность вопросов:**
1. "Как накачать бицепс?"
2. "Могу сделать 10 подтягиваний"

**Ожидаемый результат:**
- AI понимает контекст предыдущего вопроса
- Дает персонализированную программу на основе 10 подтягиваний

#### Сценарий 5: Противопоказания
**Предварительно:**
- Установите в профиле противопоказания (например, "Гипертония")

**Вопрос:**
- "Какие упражнения мне подходят?"

**Ожидаемый результат:**
- Рекомендации с учетом противопоказаний
- Предупреждения о том, чего избегать

## Проверка Fallback механизма

### Тест без интернета
1. Отключите интернет
2. Задайте вопрос AI
3. Должен сработать fallback с базовыми ответами

### Тест с неверным API ключом
1. Временно измените API ключ в `deepseek_ai_service.dart`
2. Задайте вопрос
3. Должен сработать fallback

## Производительность

### Метрики
- ⏱️ Время ответа API: ~2-5 секунд
- 💾 Размер истории: до 1000 сообщений
- 🔄 Контекст: последние 10 сообщений

### Оптимизация
- Timeout: 30 секунд
- Fallback при ошибках
- Локальное кэширование истории

## Известные ограничения

1. **API ключ в коде** - временное решение для разработки
2. **Лимиты API** - зависят от тарифа DeepSeek
3. **Контекст** - только последние 10 сообщений
4. **Язык** - в основном русский (можно расширить)

## Отладка

### Логи
Проверьте консоль на наличие ошибок:
- `DeepSeek API Error: ...` - ошибка API
- `DeepSeek Error: ...` - общая ошибка

### Проверка запросов
1. Откройте DevTools
2. Перейдите в Network
3. Найдите запросы к `api.deepseek.com`
4. Проверьте статус и ответы

# Product Context — FitMonster

## Проблема пользователя
- Люди тренируются с неправильной техникой → травмы, отсутствие прогресса
- Сложно самостоятельно контролировать питание и считать калории
- Нет единого инструмента: тренировки + питание + прогресс в одном месте

## Решение
FitMonster объединяет:
- **AI-тренер** (камера + ML) — мгновенная обратная связь по технике
- **Диет-трекер** — персонализированный план питания + дневник
- **Статистика** — визуализация прогресса (графики, календарь)

## Ценностное предложение
Приложение работает полностью офлайн, не требует дорогого оборудования — только смартфон.

## Пользовательские сценарии
1. Пользователь выбирает упражнение → включает камеру → получает реалтайм-подсказки по технике
2. Вводит антропометрию → получает план питания на неделю → ведёт дневник еды
3. Просматривает прогресс: вес, калории, тренировки за период

## Конкурентный контекст
- Аналоги: MyFitnessPal (питание), Nike Training Club (тренировки)
- Отличие FitMonster: ML-анализ техники + питание + офлайн в одном приложении

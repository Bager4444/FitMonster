# Project Brief — FitMonster

## Цель проекта
Кроссплатформенное мобильное фитнес-приложение (Flutter, iOS + Android) с тремя ключевыми функциями:
1. Проверка техники упражнений через камеру (ML Kit / pose detection)
2. Трекер питания и генератор диеты
3. Профиль пользователя и статистика прогресса

## Рамки проекта (MVP)
- 10 базовых упражнений с анализом позы в реальном времени
- База ~500 продуктов (локальная, офлайн)
- Авторизация: Email + Google (Firebase Auth)
- Хранение: Hive (локально) + Firebase (облако)
- Офлайн-режим: 100% для основных функций
- Языки: Русский (основной)
- Платформы: iOS 14+, Android 10+

## Целевая аудитория
Взрослые 18+, интересующиеся фитнесом и контролем питания (новички и опытные).

## Ограничения
- Не медицинское приложение (disclaimer обязателен)
- ML-анализ только при хорошем освещении (>80% точность)
- Без интеграций с внешними устройствами (Fitbit и т.д.) в MVP
- Монетизация не предусмотрена в MVP

# 📋 ДОКУМЕНТАЦИЯ ПРОЕКТА FITMONSTER

## 🎯 ОБЩАЯ ИНФОРМАЦИЯ

**Название проекта:** FitMonster  
**Тип:** Мобильное приложение для фитнеса с AI-анализом  
**Платформы:** Android, iOS, Web  
**Технологии:** Flutter, Dart, ML Kit, Hive  
**Версия:** 1.0.0+1  
**Статус:** Готов к продакшену  

## 📊 КРАТКОЕ ОПИСАНИЕ

FitMonster - это инновационное фитнес-приложение, использующее искусственный интеллект для анализа техники выполнения упражнений через камеру устройства. Приложение включает в себя систему питания с базой данных продуктов, систему прогресса пользователя и полностью работает в оффлайн режиме.

## 🏗️ АРХИТЕКТУРА ПРОЕКТА

### Основная архитектура: Clean Architecture

```
lib/
├── core/                    # Общие компоненты системы
│   ├── constants/          # Константы приложения
│   ├── services/           # Общие сервисы (Hive, Auth, etc.)
│   ├── theme/              # Темы и стили
│   └── widgets/            # Переиспользуемые виджеты
├── features/               # Функциональные модули
│   ├── auth/               # Модуль аутентификации
│   ├── exercises/          # Модуль упражнений и тренировок
│   ├── diet/               # Модуль питания и продуктов
│   ├── profile/            # Модуль профиля пользователя
│   └── home/               # Главная страница
└── main.dart               # Точка входа приложения
```

### Слои архитектуры:
1. **Presentation Layer** - UI компоненты (Pages, Widgets, Providers)
2. **Domain Layer** - Бизнес-логика (Models, Services, Use Cases)
3. **Data Layer** - Источники данных (Repositories, DataSources, APIs)

## 📱 ФУНКЦИОНАЛЬНЫЕ МОДУЛИ

### 1. 🏋️ Модуль упражнений (exercises/)
**Назначение:** AI-анализ упражнений через камеру

**Основные компоненты:**
- `ExerciseCameraPage` - страница с камерой и анализом
- `ImprovedRepCounter` - счетчик повторений с ML
- `WorkoutService` - управление тренировками
- `PoseDetector` - анализ позы через ML Kit

**Поддерживаемые упражнения:**
- **Динамические:** Приседания, отжимания, выпады, jumping jacks
- **Статические:** Планка, боковая планка (подсчет времени)

**Ключевые особенности:**
- Реальное время анализа (8 FPS)
- Точный подсчет повторений
- Подсчет времени для статических упражнений
- Система обратной связи
- Начисление опыта за выполнение

### 2. 🍎 Модуль питания (diet/)
**Назначение:** База данных продуктов и подсчет калорий

**Основные компоненты:**
- `FoodDatabaseService` - работа с базой продуктов
- `FoodItem` - модель продукта с КБЖУ
- `Recipe` - модель рецепта
- `FoodSearchPage` - поиск продуктов

**Возможности:**
- База данных 10000+ продуктов
- Поиск по названию
- Подсчет калорий и КБЖУ
- Избранные продукты
- Рецепты с инструкциями

### 3. 👤 Модуль профиля (profile/)
**Назначение:** Управление профилем и прогрессом

**Основные компоненты:**
- `ProfilePage` - страница профиля
- `ExperienceService` - система опыта и уровней
- `LeaderboardPage` - таблица лидеров
- `StatsService` - статистика тренировок

**Система прогресса:**
- Уровни пользователя
- Опыт за упражнения
- Статистика тренировок
- Достижения

### 4. 🔐 Модуль аутентификации (auth/)
**Назначение:** Регистрация и вход пользователей

**Основные компоненты:**
- `AuthService` - управление аутентификацией
- `LoginPage` / `RegisterPage` - страницы входа
- `User` - модель пользователя

## 💾 СИСТЕМА ХРАНЕНИЯ ДАННЫХ

### Hive NoSQL Database
Локальная база данных для оффлайн работы:

```
Hive Boxes:
├── user (5 MB)          # Профили пользователей
├── workouts (20 MB)     # История тренировок  
├── foods (50 MB)        # База продуктов (10000+)
├── recipes (10 MB)      # Рецепты
├── favorites (1 MB)     # Избранные продукты
└── settings (1 MB)      # Настройки приложения
```

### Модели данных:
- **User** - пользователь с аутентификацией
- **Exercise** - упражнение с параметрами
- **WorkoutSession** - сессия тренировки
- **FoodItem** - продукт с КБЖУ
- **Recipe** - рецепт с инструкциями

## 🤖 ML/AI КОМПОНЕНТЫ

### Google ML Kit Pose Detection
**Конфигурация:**
- **Режим:** Stream (реальное время)
- **Модель:** Base (для скорости)
- **FPS:** 8 (оптимизировано)

### Анализ упражнений:
```dart
class ImprovedRepCounter {
  // Конфигурации упражнений
  final Map<String, ExerciseConfig> _configs = {
    'squats': ExerciseConfig(
      primaryJoint: JointType.knee,
      downAngle: 130, upAngle: 170,
      exerciseType: ExerciseType.dynamic,
    ),
    'plank': ExerciseConfig(
      primaryJoint: JointType.elbow,
      downAngle: 160, upAngle: 180,
      exerciseType: ExerciseType.static,

  };
}
```

### Оптимизации производительности:

- Кэширование вычислений углов
- Умное сглаживание данных
- Таймауты обработки (100ms)

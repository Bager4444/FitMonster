# Ультра-оптимизация FPS для FitMonster

## Достигнутые улучшения

### 🚀 Целевой FPS: 7+ (фактически до 8 FPS)

## Ключевые оптимизации

### 1. Умная обработка кадров
- **Целевой FPS**: увеличен с 5 до 8 FPS
- **Пропуск кадров**: каждый 2-й вместо каждого 3-го
- **ML Kit интервал**: каждый 2-й обработанный кадр вместо каждого 3-го
- **Таймаут обработки**: 100ms для предотвращения блокировок

### 2. Оптимизация ML Kit
- **Модель**: переключена с `accurate` на `base` (быстрее в 2-3 раза)
- **Режим**: `PoseDetectionMode.stream` для потоковой обработки
- **Селективная обработка**: ML Kit запускается не на каждом кадре

### 3. Кэширование и буферизация
- **Кэш буферов изображений**: переиспользование Uint8List буферов
- **Автоочистка кэша**: каждые 5 секунд для экономии памяти
- **Оптимизированная конвертация YUV→NV21**: блочное копирование

### 4. Разрешение камеры
- **Разрешение**: понижено с `medium` до `low`
- **Формат**: `ImageFormatGroup.yuv420` для оптимальной конвертации
- **Аудио**: отключено (`enableAudio: false`)

### 5. Быстрые вычисления
- **Уверенность позы**: только ключевые точки (6 вместо всех)
- **Асинхронное сохранение**: повторения сохраняются без блокировки UI
- **Умное пропускание**: кадры без ML обработки используют предыдущие данные

## Технические детали

### Новые константы производительности
```dart
static const int _targetFps = 8;           // Целевой FPS
static const int _frameSkipRate = 2;       // Каждый 2-й кадр
static const int _mlProcessInterval = 2;   // ML Kit каждый 2-й
```

### Оптимизированная конвертация изображений
- Кэширование буферов по размеру изображения
- Блочное копирование для непрерывных данных Y-плоскости
- Оптимизированные циклы для UV-плоскостей

### Быстрая оценка уверенности
Используются только критичные точки:
- Плечи (левое/правое)
- Бедра (левое/правое)  
- Колени (левое/правое)

## Дополнительные возможности

### Ультра-оптимизированный сервис (опционально)
Создан `UltraOptimizedCameraService` с изолятами для еще большей производительности:
- Обработка ML Kit в отдельном изоляте
- Полное кэширование конвертации изображений
- Статистика производительности в реальном времени

### Мониторинг производительности
- Отображение FPS в реальном времени
- Индикация пропуска ML обработки
- Автоматическая очистка кэшей

## Рекомендации по использованию

### Для максимальной производительности:
1. Используйте устройства с Android 7.0+
2. Обеспечьте хорошее освещение
3. Избегайте фоновых приложений
4. Используйте фронтальную камеру

### Настройки качества vs производительности:
- **Максимальная производительность**: `ResolutionPreset.low` + `base` модель
- **Баланс**: `ResolutionPreset.medium` + `base` модель  
- **Максимальное качество**: `ResolutionPreset.medium` + `accurate` модель

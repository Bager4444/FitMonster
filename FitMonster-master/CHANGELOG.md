## [1.0.0] - 2026-02-01

### Добавлено
- 🤖 AI-анализ упражнений с Google ML Kit Pose Detection
- 🏋️ Поддержка динамических упражнений (приседания, отжимания, выпады)
- ⏱️ Поддержка статических упражнений с подсчетом времени (планка)
- 🍎 База данных продуктов с 10000+ наименований
- 🔍 Поиск продуктов с фильтрацией
- 📊 Система опыта и уровней пользователя
- 🎨 Современный UI с поддержкой темной/светлой темы
- 💾 Локальное хранение данных с Hive
- 🔐 Система аутентификации пользователей
- 📱 Поддержка Android, iOS и Web платформ

### Технические улучшения
- Оптимизация производительности ML анализа (8 FPS)
- Умное пропускание кадров для экономии ресурсов
- Кэширование вычислений углов суставов
- Сглаживание данных для стабильности подсчета

### Исправлено
- Проблема с подсчетом времени в статических упражнениях
- Убрано отображение технических FPS в пользовательском интерфейсе
- Исправлены критические ошибки компиляции
- Оптимизирована точность распознавания упражнений

## [0.9.0] - 2026-01-25

### Добавлено
- Базовая система распознавания упражнений
- Интеграция с ML Kit Pose Detection
- Простой счетчик повторений
- Основные страницы приложения

### Изменено
- Улучшена архитектура проекта
- Переход на Clean Architecture
- Разделение на модули по функциональности

### Технические изменения

## Типы изменений

- **Добавлено** - для новых функций
- **Изменено** - для изменений в существующей функциональности
- **Устарело** - для функций, которые скоро будут удалены
- **Удалено** - для удаленных функций
- **Исправлено** - для исправления ошибок
- **Безопасность** - для исправлений уязвимостей

# Улучшенная система распознавания упражнений

## Обзор улучшений

Создана продвинутая система анализа упражнений, которая значительно улучшает точность распознавания и качество обратной связи.

## Новые компоненты

### 1. EnhancedExerciseAnalyzer
**Файл:** `lib/features/exercises/services/enhanced_exercise_analyzer.dart`

**Ключевые возможности:**
- **Многоуровневый анализ техники** - оценка симметрии, углов, координации
- **Специализированные алгоритмы** для каждого типа упражнения
- **Адаптивное сглаживание** данных для устранения шума
- **Детальная оценка техники** с процентными показателями

**Поддерживаемые упражнения:**
- ✅ Приседания (squats) - анализ углов коленей, спины, симметрии
- ✅ Отжимания (pushups) - анализ локтей, линии тела, координации
- ✅ Выпады (lunges) - анализ переднего/заднего колена, баланса
- ✅ Jumping Jacks - анализ координации рук и ног
- ✅ Планка (plank) - анализ прямой линии тела, стабильности
- ✅ Берпи (burpees) - комплексный анализ фаз движения

### 2. SmartExerciseEngine
**Файл:** `lib/features/exercises/services/smart_exercise_engine.dart`

**Ключевые возможности:**
- **Адаптивная оптимизация производительности** - автоматическое переключение режимов
- **Интеллектуальное кэширование** результатов для экономии ресурсов
- **Объединение результатов** анализатора и счетчика повторений
- **Мониторинг FPS** и автоматическая настройка параметров

## Технические улучшения

### Алгоритмы анализа техники

#### Приседания
```dart
// Проверка симметрии коленей
final kneeDifference = (leftKnee - rightKnee).abs();
if (kneeDifference > 15) score -= 20; // Штраф за асимметрию

// Проверка угла спины
if (backAngle > 45) score -= 25; // Слишком сильный наклон

// Проверка глубины приседания
if (avgKnee > 140) score -= 15; // Недостаточная глубина
```

#### Отжимания
```dart
// Проверка симметрии локтей
final elbowDifference = (leftElbow - rightElbow).abs();

// Проверка линии тела (планка)
if (bodyLine < 160) score -= 30; // Провисание тела
```

#### Планка
```dart
// Проверка прямой линии тела
if (bodyLine < 160) score -= 40; // Сильное провисание

// Проверка угла в бедрах
if (hipAngle < 160 || hipAngle > 200) score -= 20;
```

### Адаптивная производительность

```dart
// Автоматическая настройка на основе FPS
if (avgFps < 5.0) {
    _isHighPerformanceMode = false;
    _analysisInterval = 3; // Анализируем каждый 3-й кадр
    _confidenceThreshold = 0.5;
} else if (avgFps > 8.0) {
    _isHighPerformanceMode = true;
    _analysisInterval = 1; // Анализируем каждый кадр
    _confidenceThreshold = 0.7;
}
```

### Умное кэширование

```dart
// Переиспользование результатов для экономии ресурсов
if (timeSinceLastResult < 100 && lastResult.confidence > 0.8) {
    return cachedResult; // Используем кэшированный результат
```

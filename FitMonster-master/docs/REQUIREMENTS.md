# 📋 Технические требования FitMonster

## 🎯 Системные требования

### Минимальные требования для разработки:
- **Flutter SDK**: 3.0.0+
- **Dart SDK**: 3.0.0+
- **RAM**: 8 GB
- **Свободное место**: 10 GB
- **Интернет**: Для загрузки зависимостей

### Рекомендуемые требования:
- **Flutter SDK**: 3.16.0+
- **Dart SDK**: 3.2.0+
- **RAM**: 16 GB
- **SSD**: 20 GB свободного места
- **CPU**: 4+ ядра для быстрой компиляции

## 📱 Требования к устройствам

### Android:
- **Минимальная версия**: Android 5.0 (API 21)
- **Рекомендуемая**: Android 8.0+ (API 26+)
- **RAM**: 2 GB минимум, 4 GB рекомендуется
- **Камера**: Обязательна для анализа упражнений
- **Разрешения**: Камера, хранилище

### iOS:
- **Минимальная версия**: iOS 11.0
- **Рекомендуемая**: iOS 14.0+
- **Устройства**: iPhone 6s и новее
- **RAM**: 2 GB минимум
- **Камера**: Обязательна

### Web:
- **Браузеры**: Chrome 88+, Firefox 85+, Safari 14+
- **WebGL**: Поддержка обязательна
- **Камера**: Доступ через WebRTC
- **JavaScript**: Включен

## 🔧 Инструменты разработки

### Обязательные:
- **Flutter SDK** 3.16.0+
- **Android Studio** 2022.1+ или **VS Code** 1.70+
- **Git** 2.30+
- **Chrome** (для веб-разработки)

### Дополнительные:
- **Android SDK** 34
- **Xcode** 14+ (для iOS на macOS)
- **Firebase CLI** (для веб-развертывания)
- **Fastlane** (для автоматизации)

## 🚀 Производительность

### Целевые метрики:
- **FPS анализа ML**: 8 FPS стабильно
- **Время запуска**: < 3 секунд
- **Использование RAM**: < 200 MB
- **Размер APK**: < 50 MB
- **Время отклика UI**: < 16ms (60 FPS)

### Оптимизации:
- Пропуск кадров для ML анализа
- Кэширование вычислений углов
- Ленивая загрузка данных
- Оптимизация изображений
- Минификация кода в релизе

## 🔒 Безопасность

### Требования:
- Локальное хранение данных (без отправки в облако)
- Хеширование паролей (SHA-256)
- Валидация пользовательского ввода
- Защита от SQL-инъекций (не применимо для Hive)
- Обфускация кода в релизных сборках

### Разрешения:
- **Android**: CAMERA, WRITE_EXTERNAL_STORAGE
- **iOS**: NSCameraUsageDescription
- **Web**: Camera access через WebRTC

## 🌐 Сетевые требования

### Для разработки:
- Интернет для загрузки пакетов Flutter
- Доступ к pub.dev
- GitHub для системы контроля версий

### Для пользователей:
- **Оффлайн режим**: Полная функциональность без интернета
- **Опциональный интернет**: Только для обновлений приложения
- **Трафик**: Минимальный (только обновления)

## 📊 Хранение данных

### Локальная база данных (Hive):
- **Размер**: До 100 MB данных пользователя
- **Производительность**: < 1ms для простых запросов
- **Резервное копирование**: Автоматическое в локальной файловой системе

### Структура данных:
```
Hive Boxes:
├── user (5 MB)          # Профили пользователей
├── workouts (20 MB)     # История тренировок
├── foods (50 MB)        # База продуктов
├── recipes (10 MB)      # Рецепты
├── favorites (1 MB)     # Избранное
└── settings (1 MB)      # Настройки
```

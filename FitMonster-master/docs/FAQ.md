## 🎯 Общие вопросы

### Q: Что такое FitMonster?
**A:** FitMonster - это мобильное приложение для фитнеса с искусственным интеллектом, которое анализирует ваши упражнения через камеру и помогает отслеживать питание.

### Q: Какие упражнения поддерживает приложение?
**A:** Поддерживаются:
- **Динамические**: Приседания, отжимания, выпады, jumping jacks
- **Статические**: Планка, боковая планка (с подсчетом времени)

### Q: Нужен ли интернет для работы приложения?
**A:** Нет! FitMonster работает полностью оффлайн. Все данные хранятся локально на устройстве.

### Q: Безопасны ли мои данные?
**A:** Да, все данные хранятся только на вашем устройстве и никуда не передаются.

### Q: На каких платформах работает приложение?
**A:** Android (5.0+), iOS (11.0+) и Web (современные браузеры).

## 🔧 Технические вопросы

### Q: Почему приложение требует доступ к камере?
**A:** Камера необходима для анализа ваших движений с помощью ML Kit Pose Detection. Без камеры невозможен подсчет повторений.

### Q: Сколько места занимает приложение?
**A:** Около 50 MB для установки + до 100 MB для пользовательских данных.

### Q: Какие требования к устройству?
**A:** 
- **Android**: 5.0+, 2 GB RAM, камера
- **iOS**: 11.0+, iPhone 6s+, 2 GB RAM
- **Web**: Chrome 88+, Firefox 85+, Safari 14+

### Q: Почему анализ упражнений иногда неточный?
**A:** Точность зависит от:
- Освещения (лучше при хорошем свете)
- Положения камеры (на уровне груди)
- Полного попадания в кадр
- Контрастной одежды

### Q: Можно ли использовать приложение без регистрации?
**A:** Да, но регистрация позволяет сохранять прогресс и получать опыт.

## 👨‍💻 Разработка

### Q: Как начать разработку?
**A:** 
```bash
git clone https://github.com/Bager4444/FitMonster.git
cd FitMonster
flutter pub get
flutter run
```

### Q: Какая архитектура используется?
**A:** Clean Architecture с разделением на слои:
- Presentation (UI)
- Domain (бизнес-логика)
- Data (данные)

### Q: Как добавить новое упражнение?
**A:** 
1. Добавьте упражнение в `exercises_database.dart`
2. Настройте конфигурацию в `ImprovedRepCounter`
3. Добавьте тесты
4. Обновите документацию

### Q: Какие инструменты нужны для разработки?
**A:** 
- Flutter SDK 3.16.0+
- Android Studio или VS Code
- Git
- Chrome (для веб-разработки)

### Q: Как запустить тесты?
**A:** 
```bash
flutter test                    # Unit тесты
flutter test integration_test/  # Integration тесты
```

## 🚀 Развертывание

### Q: Как собрать APK для Android?
**A:** 
```bash
flutter build apk --release --split-per-abi
```

### Q: Как подготовить приложение для App Store?
**A:** 
1. Настройте подпись в Xcode
2. Выполните `flutter build ios --release`
3. Архивируйте в Xcode
4. Загрузите в App Store Connect

### Q: Можно ли развернуть на веб?
**A:** Да:
```bash
flutter build web --release
```
Затем разместите содержимое `build/web/` на любом веб-сервере.

### Q: Как настроить CI/CD?
**A:** Используйте GitHub Actions. Пример конфигурации в [DEPLOYMENT.md](DEPLOYMENT.md#cicd-настройка).

## 🔧 Устранение неполадок

### Q: Приложение не запускается на Android
**A:** Проверьте:
- Версия Android 5.0+
- Достаточно свободного места (1+ GB)
- Разрешения для камеры включены
- Попробуйте перезагрузить устройство

### Q: ML анализ работает медленно
**A:** Оптимизации:
- Закройте другие приложения
- Используйте хорошее освещение
- Убедитесь, что устройство не перегревается
- Попробуйте перезапустить приложение

### Q: Ошибка "Camera not available"
**A:** 
- Проверьте разрешения камеры в настройках
- Закройте другие приложения, использующие камеру
- Перезапустите приложение
- Перезагрузите устройство

### Q: Данные пропали после обновления
**A:** 
- Данные хранятся локально в Hive
- При переустановке данные могут быть потеряны
- Используйте экспорт/импорт данных (планируется)

### Q: Приложение вылетает при анализе упражнений
**A:** 
- Обновите приложение до последней версии
- Очистите кэш приложения
- Проверьте свободную память (нужно 500+ MB)
- Сообщите об ошибке через GitHub Issues

### Q: Веб-версия не работает в браузере
**A:** 
- Используйте Chrome 88+, Firefox 85+ или Safari 14+
- Включите JavaScript
- Разрешите доступ к камере
- Очистите кэш браузера

### Q: Ошибки компиляции при сборке
**A:** 
```bash
flutter clean
flutter pub get
flutter packages pub run build_runner build --delete-conflicting-outputs
flutter run
```

### Q: Проблемы с Hive базой данных
**A:** 
- Удалите папку `build/`
- Выполните `flutter clean`
- Перегенерируйте адаптеры: `flutter packages pub run build_runner build`

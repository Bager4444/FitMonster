# Оптимизированная система детекции поз

## Обзор

Новая оптимизированная система детекции поз использует только 10 самых важных точек для каждого типа упражнения, что значительно повышает точность анализа и производительность системы.

## Ключевые особенности

### 🎯 Точечная оптимизация
- **10 ключевых точек** для каждого упражнения вместо всех 33
- **Специализированные наборы** точек для разных типов упражнений
- **Повышенная точность** анализа движений

### 📊 Улучшенная аналитика
- **Оценка качества** выполнения упражнения (0-100%)
- **Рекомендации по форме** в реальном времени
- **Детальная обратная связь** по технике выполнения

### 🎨 Визуальные улучшения
- **Все точки видны** - полный скелет отображается
- **Выделение ключевых точек** - важные точки подсвечиваются
- **Цветовая индикация** качества выполнения
- **Информационная панель** с детальной статистикой

## Архитектура

### OptimizedRepCounter
Основной класс для анализа движений:
```dart
class OptimizedRepCounter {
  // Анализирует позу используя только ключевые точки
  OptimizedRepCountResult analyzePose(Pose pose);
  
  // Устанавливает тип упражнения
  void setExerciseType(String exerciseId);
}
```

### Ключевые точки по типам упражнений

#### Приседания (squats, jump_squats, sumo_squats)
- Плечи (левое/правое)
- Бедра (левое/правое) 
- Колени (левое/правое)
- Лодыжки (левое/правое)
- Пятки (левая/правая)

#### Отжимания (pushups, knee_pushups)
- Нос
- Плечи (левое/правое)
- Локти (левый/правый)
- Запястья (левое/правое)
- Бедра (левое/правое)
- Левое колено

#### Кардио упражнения (jumping_jacks, burpees, etc.)
- Плечи (левое/правое)
- Локти (левый/правый)
- Бедра (левое/правое)
- Колени (левое/правое)
- Лодыжки (левое/правое)

## Компоненты

### 1. OptimizedPosePainter
Рисует позу с выделением ключевых точек:
- Все точки (белые, полупрозрачные)
- Ключевые точки (цветные, большие)
- Скелет (белые линии)
- Индикатор качества
- Легенда

### 2. KeyPointsInfoWidget
Информационная панель с:
- Статистикой детекции
- Качеством выполнения
- Списком ключевых точек
- Рекомендациями по форме

### 3. OptimizedCameraPage
Страница камеры с оптимизированным анализом:
- Превью камеры
- Наложение позы
- Счетчик повторений
- Информационная панель

## Преимущества

### 🚀 Производительность
- **Меньше вычислений** - анализ только важных точек
- **Быстрее обработка** - оптимизированные алгоритмы
- **Стабильная работа** - меньше нагрузка на процессор

### 🎯 Точность
- **Специализация** - каждое упражнение имеет свой набор точек
- **Фильтрация шума** - игнорирование неважных движений
- **Повышенный порог уверенности** - 0.6 вместо 0.5

### 📈 Аналитика
- **Качество формы** - оценка правильности выполнения
- **Рекомендации** - советы по улучшению техники
- **Детальная статистика** - полная информация о движении

## Использование

### В интерфейсе
На карточке каждого упражнения теперь две кнопки:
- **"Обычный"** - стандартный режим
- **"AI+"** - оптимизированный режим с анализом

### Программно
```dart
// Создание счетчика
final counter = OptimizedRepCounter();

// Установка типа упражнения
counter.setExerciseType('squats');

// Анализ позы
final result = counter.analyzePose(pose);

// Получение результатов
print('Повторений: ${result.repCount}');
print('Качество: ${result.exerciseQuality}');
print('Рекомендации: ${result.formCorrection}');
```

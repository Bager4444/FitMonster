# FitMonster

Фитнес-приложение на Flutter: упражнения с проверкой техники через камеру (ML Kit), диета и трекер питания, AI персональный тренер.

## Запуск

```bash
flutter pub get
flutter run
```

## Основные возможности

- 🏋️ **Упражнения с проверкой техники** — ML Kit для отслеживания позы
- 🍎 **Трекер питания** — подсчет калорий и макронутриентов
- 🤖 **AI Персональный тренер** — DeepSeek API для персонализированных рекомендаций
- 📊 **Статистика и прогресс** — отслеживание достижений
- 📅 **Календарь тренировок** — планирование и история

# FitMonster 💪

Фитнес-приложение: проверка техники упражнений через камеру (ML), диета и трекер питания.

## Документация

| Документ | Описание |
|----------|----------|
| [ТЗ.md](ТЗ.md) | Техническое задание, функциональные требования |
| [STATUS.md](STATUS.md) | Текущий статус и прогресс разработки |
| [BACKLOG.md](BACKLOG.md) | Backlog и задачи по спринтам |
| [specs/firestore_sync_plan.md](specs/firestore_sync_plan.md) | План синхронизации данных через Firebase Firestore |

## Запуск

```bash
flutter pub get
flutter run
```

## Структура приложения

- **lib/core/** — общие компоненты (тема, константы, сервисы)
- **lib/features/** — модули: exercises, diet, profile, home
- **Локальная БД пользователей (`Hive.users`)** — единая запись аккаунта: имя, email, хэш пароля, ударный режим, суммарные упражнения, время выполнения, средний процент техники, ачивки, 3 последних устройства, аллергии/противопоказания, статус подписки, мировая и региональная позиции

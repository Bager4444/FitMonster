# Анализ окон проекта FitMonster

## Общая структура приложения

Приложение FitMonster построено на Flutter и использует архитектуру с разделением на features (фичи). Основная навигация осуществляется через `HomePage` с нижней панелью навигации, которая содержит 4 основные вкладки.

---

## Основные окна приложения

### 1. HomePage (Главная страница)
**Расположение:** `lib/features/home/presentation/pages/home_page.dart`

**Описание:** Главная страница приложения с нижней панелью навигации. Использует `IndexedStack` для сохранения состояния вкладок. Содержит 4 основные вкладки:
- Упражнения (ModernExercisesPage)
- Комплексы (WorkoutComplexesPage)
- Диета (DietPage)
- Профиль (ProfilePage)

**Особенности:**
- Градиентный фон, адаптирующийся к теме
- Прозрачный AppBar
- Анимированная нижняя панель навигации

---

### 2. ModernHomePage (Альтернативная главная)
**Расположение:** `lib/features/home/presentation/pages/modern_home_page.dart`

**Описание:** Альтернативная версия главной страницы с современным дизайном. Содержит:
- Приветствие пользователя
- Быструю статистику (калории, минуты, дни подряд)
- Карточки быстрых действий (Начать тренировку, История тренировок)
- Недавнюю активность

**Особенности:**
- Анимации появления элементов
- Градиентный фон
- Готова для конвертации через DhiWise

---

### 3. LoginPage (Страница входа)
**Расположение:** `lib/features/auth/presentation/pages/login_page.dart`

**Описание:** Простая страница авторизации с возможностью входа как гость.

**Функционал:**
- Создание нового пользователя через AuthService
- Переход на главную страницу после входа

---

## Окна модуля "Упражнения"

### 4. ModernExercisesPage (Современная страница упражнений)
**Расположение:** `lib/features/exercises/presentation/pages/modern_exercises_page.dart`

**Описание:** Основная страница для выбора и начала упражнений. Отображается как первая вкладка в главном меню.

**Функционал:**
- Фильтрация по категориям (Все, Кардио, Силовые, Растяжка, Функциональные)
- Поиск упражнений
- Быстрый старт (случайное упражнение, последнее упражнение)
- Сетка упражнений с карточками
- Переход к деталям упражнения или сразу к камере

**Особенности:**
- Анимации появления
- Градиентные карточки для каждого упражнения
- Emoji-иконки для упражнений

---

### 5. ExercisesPage (Классическая страница упражнений)
**Расположение:** `lib/features/exercises/presentation/pages/exercises_page.dart`

**Описание:** Альтернативная версия страницы упражнений с классическим дизайном.

**Функционал:**
- Поиск упражнений
- Фильтры по категории и сложности
- Список упражнений в виде карточек
- Переход к деталям упражнения

---

### 6. ExerciseDetailPage (Детали упражнения)
**Расположение:** `lib/features/exercises/presentation/pages/exercise_detail_page.dart`

**Описание:** Страница с подробной информацией об упражнении.

**Содержит:**
- Название и категорию упражнения
- Краткую информацию (сложность, калории/мин)
- Описание упражнения
- Пошаговые инструкции выполнения
- Частые ошибки
- Работающие мышечные группы
- Кнопку "Начать упражнение"

**Особенности:**
- SliverAppBar с градиентом
- Адаптивный дизайн под тему

---

### 7. ExerciseCameraPage (Камера для выполнения упражнения)
**Расположение:** `lib/features/exercises/presentation/pages/exercise_camera_page.dart`

**Описание:** Основное окно для выполнения упражнения с использованием камеры и ML-анализа.

**Функционал:**
- Превью камеры (фронтальная/задняя)
- ML Kit Pose Detection для анализа позы
- Подсчет повторений в реальном времени
- Оценка техники выполнения
- Обратная связь пользователю
- Обратный отсчет перед началом
- Статистика (повторения, техника, время)
- Сохранение результатов тренировки
- Начисление опыта за выполнение

**Особенности:**
- Overlay с отрисовкой скелета позы
- Индикатор записи
- Большой счетчик повторений
- FPS мониторинг
- Таймер тренировки
- Поддержка статических упражнений (планка)

---

### 8. WorkoutComplexesPage (Комплексы упражнений)
**Расположение:** `lib/features/exercises/presentation/pages/workout_complexes_page.dart`

**Описание:** Страница с готовыми программами тренировок (комплексами упражнений). Отображается как вторая вкладка в главном меню.

**Функционал:**
- Фильтрация по категории и сложности
- Кнопка для прохождения фитнес-теста
- Список комплексов с описанием
- Информация о каждом комплексе (упражнения, время, сложность)
- Настройка времени отдыха перед началом
- Переход к выполнению комплекса

**Особенности:**
- Градиентные карточки комплексов
- Анимации появления
- Emoji-иконки

---

### 9. ComplexWorkoutPage (Выполнение комплекса)
**Расположение:** `lib/features/exercises/presentation/pages/complex_workout_page.dart`

**Описание:** Страница для последовательного выполнения упражнений из комплекса.

**Функционал:**
- Последовательное выполнение упражнений комплекса
- Обратный отсчет перед каждым упражнением
- Экран отдыха между упражнениями
- Настройка времени отдыха во время тренировки
- Прогресс-бар выполнения комплекса
- Экран завершения комплекса

**Состояния:**
- Экран упражнения (использует ExerciseCameraPage)
- Обратный отсчет
- Отдых
- Завершение

---

### 10. WorkoutHistoryPage (История тренировок)
**Расположение:** `lib/features/exercises/presentation/pages/workout_history_page.dart`

**Описание:** Страница с историей всех выполненных тренировок.

**Функционал:**
- Общая статистика (тренировок, повторений, минут)
- Список тренировок с деталями
- Фильтрация и сортировка
- Детальная информация о каждой тренировке
- История повторений с оценкой техники

**Отображает:**
- Название упражнения
- Дата и время
- Количество повторений
- Длительность
- Средняя оценка техники
- Прогресс-бар выполнения цели

---

### 11. FitnessAssessmentPage (Фитнес-тест)
**Расположение:** `lib/features/exercises/presentation/pages/fitness_assessment_page.dart`

**Описание:** Страница для прохождения фитнес-теста для определения подходящего уровня тренировок.

**Функционал:**
- Последовательное выполнение тестовых упражнений
- Тест отжиманий (1 минута)
- Тест приседаний (1 минута)
- Расчет рекомендаций на основе результатов
- Отображение рекомендуемых комплексов

**Результаты:**
- Уровень: Начинающий / Средний / Продвинутый
- Описание рекомендаций
- Список подходящих комплексов

## Окна модуля "Диета"

### 12. DietPage (Страница диеты)
**Расположение:** `lib/features/diet/presentation/pages/diet_page.dart`

**Описание:** Главная страница модуля диеты. Отображается как третья вкладка в главном меню.

**Функционал:**
- Проверка наличия профиля пользователя
- Если профиль отсутствует - предложение настроить
- Если профиль есть - отображение TabBar с двумя вкладками:
  - Статистика (DietDashboardPage)
  - Дневник (FoodLogPage)

**Особенности:**
- Автоматическая загрузка профиля
- Обновление при изменении профиля

---

### 13. DietDashboardPage (Дашборд диеты)
**Расположение:** `lib/features/diet/presentation/pages/diet_dashboard_page.dart`

**Описание:** Страница со статистикой питания за неделю.

**Содержит:**
- Карточка "Сегодня" с текущими показателями (калории, БЖУ)
- График калорий за неделю (BarChart)
- Круговая диаграмма распределения БЖУ (PieChart)
- Средние показатели за неделю
- Выбор даты для просмотра статистики

**Особенности:**
- Использует библиотеку fl_chart для графиков
- Адаптивный дизайн

---

### 14. FoodLogPage (Журнал питания)
**Расположение:** `lib/features/diet/presentation/pages/food_log_page.dart`

**Описание:** Страница для ведения дневника питания за день.

**Функционал:**
- Отображение записей по приемам пищи (завтрак, обед, ужин, перекусы)
- Прогресс-бары калорий и макронутриентов
- Навигация по датам (предыдущий/следующий день)
- Выбор даты через календарь
- Добавление продуктов через диалог
- Удаление записей
- Настройка профиля

**Отображает:**
- Прогресс калорий (с цветовой индикацией)
- Прогресс БЖУ (белки, жиры, углеводы)
- Список приемов пищи с деталями

---

### 15. ProfileSetupPage (Настройка профиля)
**Расположение:** `lib/features/diet/presentation/pages/profile_setup_page.dart`

**Описание:** Страница для настройки профиля пользователя для расчета калорий.

**Функционал:**
- Ввод данных: возраст, рост, вес
- Выбор пола (мужской/женский)
- Выбор уровня активности
- Выбор цели (похудеть/поддержать/набрать)
- Расчет и отображение результатов:
  - BMI (индекс массы тела)
  - BMR (базовый метаболизм)
  - TDEE (общий расход калорий)
  - Целевые калории
  - Макронутриенты (белки, жиры, углеводы)
- Сохранение профиля

**Особенности:**
- Использует формулу Mifflin-St Jeor
- Валидация введенных данных
- Информативные карточки результатов

---

## Технические детали

### Используемые технологии:
- **Flutter** - основной фреймворк
- **Provider** - управление состоянием
- **Hive** - локальное хранилище
- **ML Kit Pose Detection** - анализ позы
- **Camera** - работа с камерой
- **fl_chart** - графики и диаграммы
- **mobile_scanner** - сканирование штрих-кодов

### Архитектура:
- Разделение на features (auth, diet, exercises, home, profile)
- Каждая feature содержит:
  - `data` - базы данных и сервисы данных
  - `domain` - модели и бизнес-логика
  - `presentation` - UI (pages и widgets)

### Темы:
- Поддержка светлой и темной темы через ThemeProvider
- Градиентные фоны
- Адаптивные цвета

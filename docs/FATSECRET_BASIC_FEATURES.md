# Полный функционал FatSecret Platform API - Basic версия

**Дата создания:** 18 января 2026  
**Версия:** Basic (Бесплатная)  
**Источник:** [FatSecret Platform API](https://platform.fatsecret.com/platform-api)

---

## 📋 Обзор

**FatSecret Platform API Basic** — бесплатная версия API для разработчиков, предоставляющая доступ к крупнейшей базе данных продуктов питания и питания.

### Основные характеристики Basic версии

- ✅ **Бесплатный доступ** для разработки и тестирования
- ✅ **Ограниченное количество API вызовов** (точное количество уточняется при регистрации)
- ✅ **Базовая функциональность** поиска и получения данных
- ⚠️ **Требуется атрибуция FatSecret** в приложении
- ❌ **Нет доступа к расширенным функциям** (Image Recognition, NLP)

## 🔑 Доступные методы API в Basic версии

### 1. Food Methods (Методы работы с продуктами)

#### ✅ `foods.search` - Поиск продуктов
**Описание:** Поиск продуктов по названию с поддержкой автодополнения

**Параметры:**
- `search_expression` (обязательный) - поисковый запрос
- `page_number` (опционально) - номер страницы (по умолчанию 0)
- `max_results` (опционально) - максимальное количество результатов (по умолчанию 20, максимум 50)

**Пример запроса:**
```
GET /rest/server.api?method=foods.search&search_expression=apple&page_number=0&max_results=20
```

**Возвращает:**
- Список продуктов с базовой информацией (ID, название, калории на 100г)
- Общее количество найденных продуктов
- Поддержка пагинации

**Использование:**
- Поиск продуктов в `AddFoodDialog`
- Автодополнение при вводе названия продукта

---

#### ✅ `food.get` - Получение детальной информации о продукте
**Описание:** Получение полной информации о продукте, включая макронутриенты, микронутриенты, порции, аллергены

**Параметры:**
- `food_id` (обязательный) - ID продукта из FatSecret

**Пример запроса:**
```
GET /rest/server.api?method=food.get&food_id=33691
```

**Возвращает:**
- Полная информация о продукте:
  - Название (на разных языках)
  - Калории, белки, жиры, углеводы
  - Микронутриенты (витамины, минералы) - где доступно
  - Список доступных порций (servings)
  - Информация об аллергенах (10 типов)
  - Веган/вегетарианский статус
  - URL изображения продукта
  - Описание продукта
  - Категория продукта

**Использование:**
- Показ детальной информации при выборе продукта
- Отображение различных порций для выбора
- Проверка аллергенов

---

#### ✅ `food.find_id_for_barcode` - Поиск продукта по штрих-коду
**Описание:** Поиск продукта по UPC/EAN штрих-коду

**Параметры:**
- `barcode` (обязательный) - штрих-код продукта (UPC/EAN)

**Пример запроса:**
```
GET /rest/server.api?method=food.find_id_for_barcode&barcode=1234567890
```

**Возвращает:**
- `food_id` - ID продукта в FatSecret (если найден)
- Ошибка, если продукт не найден

**Использование:**
- Сканирование штрих-кодов для быстрого добавления продуктов
- Интеграция с камерой для сканирования

**Ограничения:**
- Покрытие базы данных: 90%+ глобальных штрих-кодов
- Некоторые региональные продукты могут отсутствовать

### 3. Food Diary Methods (Методы работы с дневником питания)

#### ✅ `food_entries.create` - Создание записи в дневнике питания
**Описание:** Добавление продукта в дневник питания пользователя

**Параметры:**
- `food_id` (обязательный) - ID продукта
- `serving_id` (обязательный) - ID порции
- `number_of_units` (обязательный) - количество порций
- `meal` (обязательный) - тип приема пищи (Breakfast, Lunch, Dinner, Snacks, Other)
- `date` (обязательный) - дата в формате YYYY-MM-DD

**Пример запроса:**
```
POST /rest/server.api?method=food_entries.create&food_id=33691&serving_id=123&number_of_units=1&meal=Breakfast&date=2026-01-18
```

**Возвращает:**
- ID созданной записи
- Подтверждение успешного создания

**Использование:**
- Добавление продуктов в дневник питания
- Синхронизация с локальным журналом питания

**Примечание:** Требует OAuth 3-legged для доступа к данным пользователя FatSecret

---

#### ✅ `food_entries.get` - Получение записей дневника питания

**Пример запроса:**

**Возвращает:**
- Список записей дневника питания за указанную дату
- Итоговые калории и макронутриенты за день

**Использование:**
- Синхронизация дневника питания с FatSecret
- Отображение записей пользователя

**Примечание:** Требует OAuth 3-legged

## 🔐 Аутентификация

### OAuth 1.0a
Все запросы к FatSecret API требуют OAuth 1.0a аутентификации:

**Типы OAuth:**
1. **2-legged OAuth** - для публичных данных (поиск продуктов, рецептов)
2. **3-legged OAuth** - для данных пользователя (дневник питания, вес)

**Для Basic версии:**
- ✅ 2-legged OAuth достаточно для поиска продуктов и рецептов
- ✅ 3-legged OAuth опционально для синхронизации с аккаунтом FatSecret

## 📈 Рекомендации по использованию Basic версии

### Оптимизация запросов
1. **Кэширование результатов поиска** на 24 часа
2. **Кэширование деталей продуктов** на 7 дней
3. **Локальная база популярных продуктов** как fallback
4. **Debounce для поиска** - не более 1 запроса в секунду

### Стратегия работы с лимитами
1. **Приоритизация:** Использовать API только для поиска, детали кэшировать
2. **Офлайн-режим:** Сохранять недавно использованные продукты локально
3. **Умный поиск:** Показывать результаты из кэша сначала, затем обновлять через API

### Миграция на Premier
Когда стоит переходить на Premier:
- 📈 Рост пользователей (>1000 активных пользователей)
- 📈 Превышение лимитов Basic версии
- 📈 Необходимость Image Recognition или NLP
- 📈 Требование white label
